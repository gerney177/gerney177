# 안녕하세요, 김태건입니다.

AI 시스템을 설계하고 구현하는 개발자입니다. 데이터 수집부터 검색·추론·배포까지 이어지는 흐름을 만들고, 작은 모델과 제한된 환경에서도 실제로 동작하는지 끝까지 확인하는 일에 관심이 있습니다.

- 홍익대학교 컴퓨터공학과 (2027.02 졸업예정)
- SKALA (SK AX 주관 AI 인재 양성 과정) 참여 중
- 주요 관심사: RAG · VLM · 온디바이스 AI · 경량 모델
